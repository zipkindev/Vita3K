# v1.3.3-win11merge.6 — Automatic texture preparation

Experimental diagnostic candidate, compared with .5. Primary validation target:
Windows on Lenovo Legion Go. Other handhelds are unvalidated.

## Added

- Automatic per-game texture preparation UI setting: use compatible profiles at
  game launch and learn/update retained content at normal game shutdown.
- Saved PVRTC profiles bounded to64MiB per game and1GiB total, with least-recent-use
  pruning, cross-process writer locking and orphan temporary-file cleanup.
- Clear-this-game and clear-all saved-profile controls while no game is active.
  Saves, game data and shader/pipeline caches remain separate.
- UTF-8 profile identity comparison fix, automatic lifecycle/settings/storage tests.
- Runtime and matching diagnostics downloads from one optimized EXE/PDB build.
- README explanation and explicit Vita3K, Vita3K-Plus and Vita3K-nx attribution.

Automatic .6 gameplay validation is pending. Preparation still covers eligible
PVRTC formats only, has a5s soft deadline and bounded file/scratch memory, and can
add loading time. No runtime prediction, GPU pre-upload or JIT warming is added.
RAM budget remains independently selectable; default feature setting remains off.

## Build and downloads

Built optimized on the dedicated self-hosted Windows runner. Require the complete
Windows CTest suite, manifest hash verification, matching EXE/PDB GUID+age and live
native symbol checks before staging. Exact source, recipe, dependencies, support
patches, toolchain and EXE/PDB hashes accompany the built packages and release.
Runtime contains the optimized emulator; diagnostics contains its exact PDB and
build evidence. No games, firmware, licenses, saves, texture profiles or traces
are distributed. Original project licenses and copyright notices are preserved.
