# v1.3.3-win11merge.16 — upstream correctness trial

Separate Windows x64 test candidate based on `.15`, importing two selected mainline fixes:

- Vertex COLOR0/COLOR1 outputs are clamped to [0, 1], adapted from [c5f7c750f](https://github.com/Vita3K/Vita3K/commit/c5f7c750f6f243c6221d5a4915c44142a11796bf), by nishinji. Candidate shader-cache version advances from 18 to 19 so old generated shaders cannot hide the change. Expect initial shader/pipeline rebuilding in this separate installation; existing installations and their caches are retained.
- Enforce the user-main-memory allocation budget reported by `sceKernelGetFreeMemorySize`, adapted from [395a1c163](https://github.com/Vita3K/Vita3K/commit/395a1c1635b61c56b6473e24fc8733ec616546c4), by DA and credited contributors. Budget calculation is shared with free-memory reporting, checked under the existing allocation lock with 64-bit addition before allocating. This older Plus branch lacks mainline's newer partition masks: eligibility follows its existing allocation/free accounting (CDRAM and both supported PHYCONT types excluded, other types counted as user). No unrelated memory accounting migration is included.

The guest budget is 256 MiB plus the game's ATTRIBUTE2 expansion allowance, separate from the 512 MiB host decoded-texture cache. Existing texture learning, decoding, scheduler, controls, audio and diagnostic policies remain unchanged. The allocator cleanup and CPU fault/wait/timer changes are not included in this first candidate.

A native `sysmem-budget` regression target checks all expansion modes, exact/over-budget boundaries, capacity after a freed-size reduction, partition exclusions, arithmetic overflow and a 512 MiB devkit probe. These exercise the production budget policy; full guest allocation/free behavior still requires emulator testing. All existing CTests must also pass. Optimized runtime and exact full PDB/build evidence are packaged separately, with source, dependency and EXE/PDB identity retained in provenance.

Test in sequence: verify visuals/controls and startup, allow new shaders to build, then run Chenghou Project Rapier four laps at 512 MiB. Compare a warmed repeat and a fresh process using the same learned profile. Check weapon colours/effects, menus and save/normal exit. This is a correctness trial; no performance improvement is claimed before measurement. The original Vita3K, Vita3K-Plus and Vita3K-nx projects retain their existing attribution.
