# v1.3.3-win11merge.18 — invalid guest code trial

Builds on `.17` and narrowly adapts mainline [6fe288365](https://github.com/Vita3K/Vita3K/commit/6fe288365065987681adcfd1daad2a64f3b29846), attributed to BreDoyliesSea and credited contributors. A fetch from the Vita's first 4 KiB page fails immediately and the resulting NoExecuteFault ends the guest function as WaitForInterrupt does, with register diagnostics. The Vita page size is explicit and independent of host page size.

Plus already handles invalid fetches and has richer crash diagnosis. Preserve that behavior outside the guest first page, including treating other unmapped-code faults as crashes; do not turn every arbitrary NoExecuteFault into a normal return. Retain JIT invalid-read reporting and all existing hooks. This is an intentional narrower adaptation than upstream's generic exception handler.

A dedicated invalid-code-policy CTest exercises real Dynarmic ARM and Thumb execution: branch from a valid page to zero, another first-page address, its boundary and an unmapped address outside it; require one NoExecuteFault and bounded execution. It uses the production first-page predicate but does not instantiate the entire emulator CPU wrapper; full guest lifecycle/gameplay validation remains required. Existing JIT/profile tests must pass too.

Test only after `.16` and `.17`, retaining 512 MiB cache and the same learned seed in separate installations. No null-pointer event or race pause has been proven to require this fix in WipEout; no performance improvement is claimed. The kernel wait/callback/timer series remains separate and is not included. Matching optimized EXE/full PDB and complete provenance are retained.
