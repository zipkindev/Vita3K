# Vita3K-Go .33 — native render-pass isolation

Diagnostic loading-test candidate based on `.32`. No performance or device-loss resolution is claimed before runtime validation.

Pipeline-library keys now include the actual native render-pass handle for pre-rasterization, fragment shader and fragment output subsets. This prevents guest-format hints from allowing cross-pass reuse without a complete native compatibility signature. Vertex-input libraries still share across passes; same-pass reuse is preserved. The conservative isolation may create additional libraries for otherwise compatible load/store variants.

A process-local diagnostic control, `VITA3K_DISABLE_PIPELINE_LIBRARIES=1`, disables graphics pipeline libraries and keeps the existing monolithic creation path. Unset the variable or set it to `0` for capability-gated library use. It never forces support on an unsupported GPU. The startup `PIPEGPL` line distinguishes hardware capability, enabled state and control override.

Early shader preparation, exact-recipe learning and async draw compilation remain independent. Disabling libraries does not disable early preparation or enable skipped draws. Restart the emulator to change this control; do not change it while a process is running.

Loading validation uses the same frozen texture/JIT/exact profiles, 512 MiB decoded cache and async draw compilation off. Vulkan validation is enabled only for this diagnostic check. Matching optimized EXE/PDB provenance accompanies the build. No production installation or Playnite mapping is changed.
