# v1.3.3-win11merge.14 — Texture decoding UI and community findings

This experimental Windows x64 prerelease follows `.13`'s bounded texture learning and profile merging, retaining `.11`'s decoded-cache behavior. WipEout 2048 on Legion Go remains the primary performance target. The `.12` retention experiment is excluded. No new decoding, cache admission, scheduler or JIT-preparation algorithm is introduced by this UI release.

## Test status and evidence

The preceding `.13` clean 90-second Chenghou Rapier fresh-process run at 512 MiB had median presentation interval 33.359 ms, p99 35.296 ms, one 97.012 ms interval near recording start and none above 100 ms. The owner reported “felt flawless.” Normal-close merging retained all 7,281 prior exact texture inputs and added 68, with no history drops or evictions. These results describe `.13`, not an unperformed `.14` gameplay test. Sequential order, retained disk caches and varying race events limit comparisons.

The first `.14` attempt exposed a group-heading width problem in the native layout check; it was not released. The corrected source must pass all 19 native Windows tests, including the unchanged small-window visibility assertions, before packaging. Final job, artifact identities and Go staging results are recorded on the release page. `.14` gameplay validation remains pending owner testing.

## Downloads and setup

The **runtime ZIP** contains one optimized RelWithDebInfo/LTO executable and dependencies. The optional **diagnostics ZIP** contains the exact matching PDB and build evidence; it is not a different or unoptimized executable. Verify archive/file hashes and PDB GUID/age from the same release. LibAtrac9 is compiled into this build; players do not need to find a separate ATRAC9 codec. Install the supported Microsoft Visual C++ x64 runtime and keep all bundled DLLs/plugins together.

Use **Settings → Texture Decoding (Perf. Tweaks)** to select a nonzero cache budget and enable automatic preparation. Learning is per game, merges compatible previous input and saves on normal close. A decoded budget of 512 MiB is our current Go test setting, not a universal recommendation. Learning can add up to 64 MiB of compressed history plus bounded metadata beyond that budget. Saved profiles are limited to 64 MiB per game and 1 GiB total; preparation has a five-second soft deadline and can be partial. It currently supports eligible PVRTC inputs, not every texture format or bottleneck.

Keep a working installation and frontend mapping intact when testing. The separate Go trial starts from `.13`'s latest 7,349-record learned profile and copied saves/settings. Full game-derived data, firmware, saves, learned texture payloads, private traces and credentials are not included in public downloads.
