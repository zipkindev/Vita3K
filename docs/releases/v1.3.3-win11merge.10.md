# v1.3.3-win11merge.10 — Synchronization telemetry and Performance settings

Based on `.9`, retaining the tested texture preparation, bounded parallel decoding and rolling JIT observer. The separate `.7` upstream import candidate is excluded. No synchronization scheduling or timeout policy changes.

- Add opt-in synchronization API-span telemetry with native TID/QPC, guest callsite context, raw results, bounded session/kind summaries and a 65,536-record rolling detail buffer. Detail retains spans of at least 2 ms. Try-lock contention drops are counted; outstanding spans and overwritten detail are explicit. This is diagnostic measurement, not a performance fix.
- Fix the GPU grid collision where Automatic Texture Preparation and the Hacks group both used row 3. A direct **Settings → Performance** menu entry and dedicated settings tab now group cache size, parallel decoding, automatic per-game preparation and both profile-clear actions, with brief benefit/trade-off descriptions and clear RAM/disk limits.
- Wire parallel decoding and optional texture/JIT/wait telemetry switches through global/per-game persistence and next-launch reporting. Diagnostic switches default off; parallel decoding defaults on. Existing diagnostic environment overrides remain available.
- Add concurrent/rolling/bounded wait-recorder tests, extend settings persistence and serial/parallel tests, and add an offscreen Qt geometry regression check at compact and larger dialog sizes, including category-order checks.

Telemetry uses additional memory beyond the 512 MiB texture trial. Selected API elapsed spans can overlap and include driver work, preemption, relocking and bookkeeping; they cannot establish pure OS sleep or wait ownership alone. Normal close saves bounded reports. Existing source and licenses from Vita3K, Vita3K-Plus and Vita3K-nx retain their attribution. New runtime and matching-symbol downloads use the same optimized executable. Build provenance and Go compatibility/race validation are recorded separately; no new speedup is claimed.
