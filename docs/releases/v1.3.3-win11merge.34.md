# Vita3K-Go .34 — full pipeline-library isolation

Diagnostic candidate for the WipEout loading device loss. Graphics pipeline libraries now require explicit process-local opt-in (`VITA3K_ENABLE_PIPELINE_LIBRARIES=1`). The off path removes both library extensions, unlinks the feature structure, and uses monolithic pipeline creation. `VITA3K_DISABLE_PIPELINE_LIBRARIES=1` overrides opt-in.

`VITA3K_DISABLE_EARLY_PIPELINE_PREPARATION=1` independently bypasses the .32 HLE draw-time pair hook. Existing program-creation preparation, saved recipes, dynamic scheduling and texture retention remain active. Async pipeline compilation is unchanged.

The .33 libraries-off control still enabled the extensions. A recorded healthy-driver-cache/validation-off launch reproduced device loss before debugger attachment, so neither a corrupt driver cache nor validation alone explains that failure. The initiating GPU fault remains unproven. This build is for automated menu and track-load isolation, not a performance claim or release recommendation.
