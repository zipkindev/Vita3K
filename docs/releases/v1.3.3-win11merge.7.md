# v1.3.3-win11merge.7 — Reviewed mainline test candidate

Experimental comparison build based on automatic-texture .6. Preserve .6 as the
reference. No complete mainline merge or universal performance gain is claimed.

## Selected upstream changes

- Vertex COLOR0/COLOR1 output clamp to[0,1], adapted from Vita3K/Vita3K
  c5f7c750f6f243c6221d5a4915c44142a11796bf. Advance this Plus-derived shader cache
  version18->19 rather than applying mainline's14->15 value. Existing cache files
  are preserved; incompatible generated shaders must be rebuilt in this separate
  installation. First-run shader preparation can affect timing.
- Bitmap allocator modernization only, adapted from Vita3K/Vita3K
  dbde5491789bb5bc8cfea5d99e919518161a5dfc. The rest of that broad cleanup is not
  included. Retain upstream author attribution and full source references.
- Add a slot-by-slot reference-model test:220000random allocation/free/count
  operations with both fit policies, partial-word bounds, empty allocator and
  growth. Add a regression for best-fit placement affected by nonexistent tail
  slots. New allocator passed locally; this is not a Go speed benchmark.

## Validation and limits

Automatic texture preparation/UI/1GiB saved-profile quota and clear controls remain
from .6. Build optimized with the dedicated Windows runner, full matching PDB and
complete CTest suite. Require Go visual/control/music/save and cold/warm gameplay
checks before promotion. Shader generation integration and Go allocator workload
performance are not established by the local model test. Do not attribute shader
rebuild costs to decoded-texture caching or compare mixed cold shader states.

Not included: duplicate first-page instruction guard, guest-memory allocation
policy changes, Boost/FFmpeg dependency changes, or unrelated modernization. Those
need separate compatibility/dependency review. There are no additional unreviewed
upstream imports in this candidate. Runtime/symbol download manifests identify the
exact source, recipe, dependencies, patches and EXE/PDB pair.
