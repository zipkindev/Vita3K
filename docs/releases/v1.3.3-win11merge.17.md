# v1.3.3-win11merge.17 — focused bitmap allocator trial

Builds on `.16` (vertex colour clamping and guest memory budget enforcement) and adds only the allocator-related portion of mainline [dbde54917](https://github.com/Vita3K/Vita3K/commit/dbde5491789bb5bc8cfea5d99e919518161a5dfc), attributed to nishinji and credited contributors. The 114-file general C++ cleanup is excluded.

Bitmap free-run scanning uses standard bit operations and respects max_offset when choosing a best-fit run. Added words start free; free-bit counting uses popcount. Keep upstream's regression for an invalid tail run hiding a valid allocation and add deterministic fragmented/multiword comparisons against a simple bounded reference allocator, checking selected offsets and allocation bit changes. All existing memory and full CTest targets must pass on Windows.

This candidate keeps `.16`'s shader-cache version 19, texture cache/preparation, Plus scheduler, CPU fault policy and optional telemetry. Test `.16` first, then `.17` with the same latest normally saved profile at 512 MiB in separate installations. The upstream allocator-specific speed claim is not a measured whole-game gain; no performance improvement is asserted before testing. Optimized runtime and matching full PDB retain exact provenance.
